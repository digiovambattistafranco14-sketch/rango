Ajustes y clave de la IA

Para que Rango pueda pensar necesita una clave gratuita de Google. Se consigue una sola vez:

  1. Entrá a aistudio.google.com/apikey con una cuenta de Google.
  2. Tocá "Create API key" (crear clave).
  3. Copiá la clave y pegala acá abajo.

Si el modelo no responde, la página prueba sola con otros de respaldo. Si querés cambiarlo, se hace acá.

Música: decí "Hola Rango, poné cumbia de Los Palmeras" (o el artista o canción que quieras). Para que ande tiene que estar abierto con "Iniciar Rango". También entiende: pausá, seguí, siguiente, subí o bajá el volumen, y pará la música.

Registro técnico (si algo falla, copialo y mandámelo) 
Todavía no hay nada registrado.

En el plan gratuito, Google puede usar lo que se le pregunte para mejorar sus productos. Mejor no decir datos personales, contraseñas ni números de tarjeta.
